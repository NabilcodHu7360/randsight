# Draft: asking Smogon about Randsight

Post this before submitting to the Web Store. The answer could change what you
ship, and finding that out after people have installed it is worse for everyone.

**Where:** Smogon Forums → Pokémon Showdown → the Programming / Tools subforum
is the usual home for client extensions. If you get no reply in a week, the
Showdown Discord's development channel is the faster route.

**How to read the room first:** search the forum for *Showdex* and for
*Randbats Tooltip* before posting. Both are widely used and neither has been
asked to stop, which is genuinely useful context — but neither of them gives
switch advice or damage numbers, which is exactly the part worth asking about.

## The post

**Title:** `Checking in before release: a Random Battle set-prediction extension`

---

Hi — I've built a Chrome extension for Random Battles and I'd rather ask about
it now than find out after release that it isn't welcome.

**What it does.** It reads the battle state the client already holds and shows a
panel with, for each opposing Pokémon, the probability of each move being in the
slots you haven't seen yet, plus item, ability, Tera type and speed. Everything
is conditioned on what has already been revealed, so it tightens as the game
goes on. It also has a damage tab (both directions, using the predicted item and
ability rather than a single guess) and a tab that ranks my own team by how much
HP survives their worst realistic hit.

**Where the data comes from.** The set percentages are the public files from
pkmn/randbats. On top of those I ship sampled tables generated by running
Showdown's own `Teams.generate()` offline, because the published data is
marginal — it tells you how often a move appears, but not which moves and items
go together, and the generator picks the item from the moves.

**How it reads the battle.** It runs in the page and reads `battle.farSide`,
`battle.myPokemon` and so on, with a fallback that parses the protocol frames
off the socket. It does not patch any Showdown method, does not touch
`battle.subscription`, and never sends anything over the socket — it only reads.
It writes nothing to the page except its own overlay element.

**What I'm actually asking.**

1. Is a tool like this acceptable on the ladder? I know Showdex and the pkmn
   Randbats Tooltip both exist and are widely used, but both stop at showing
   set data. Mine adds damage calculation and a switch recommendation, and I
   don't want to assume that's the same conversation.

2. Is there a line you'd want me to stay on the right side of? I'm happy to
   drop the switch-recommendation tab, or gate features by format, if that's
   the difference between fine and not fine.

3. The panel loads Pokémon sprites from `play.pokemonshowdown.com/sprites/`.
   That's hotlinking your assets from a third-party extension. Would you rather
   I bundled them, or is the current behaviour fine? It's one request per
   Pokémon per battle and only when the client's own icon function isn't
   available.

4. Anything about generating and redistributing sampled data from
   `Teams.generate()` that I should handle differently? Showdown is credited and
   its MIT notice ships with the extension, but I'd rather you tell me if that's
   not the right form.

It's MIT, no data collection of any kind, no server, and the source is open.
Happy to change or pull anything you're not comfortable with.

Thanks.

## If they say no, or say "not the advice parts"

The cleanest fallback is a build flag that ships Sets only and drops the Damage
and Switch tabs — that is the version closest to what already exists and is
tolerated. `content.js` already computes those tabs separately from the Sets
view, so removing them is a small change, not a rewrite.

## If they don't reply

Silence is not permission, but it also isn't a prohibition. If two weeks pass
with no answer from the forum or the Discord, publishing while making the
tool's behaviour completely explicit in the listing — which the current
description does — is a defensible position. Say plainly in the listing what it
reads and what it recommends, so nobody installs it under a misapprehension.

Chrome extension · Pokémon Showdown

Randsight

Keeps a running estimate of what the opposing team is holding, and tightens it every time they reveal a move, an item or a Tera type. Not a set list — a posterior.

Download Source Privacy

Why a model and not a lookup

Random Battles draw a Pokémon's moves from a role, and the generator picks the item from the moves it chose. What you have already seen genuinely changes what is still possible.

The published data only gives marginals — how often each move appears — which cannot answer a conditional question. Randsight samples the joint distribution from Showdown's own team generator and ships it, so a revealed item tells it something about the moveset and vice versa. Measured against the algorithm both other extensions use, on 15,000 held-out Pokémon:

Log loss 0.147 against 0.271, with three moves revealed.

Naming their item

88.0% against 84.7% — and a revealed item improves the move prediction, which theirs cannot use at all.

Numbers that add up

With two slots left, their displayed percentages sum past two on 23% of Pokémon. Ours: 0.

Install

Not on the Chrome Web Store yet. Loading it unpacked takes a minute.

  1. Download the zip and unzip it somewhere permanent — Chrome reads the folder off disk every launch.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the folder containing manifest.json.
  4. Start a Random Battle. The panel appears by itself, and a guide to reading it opens on first install.

What it collects

Nothing. No account, no analytics, no telemetry, and no server belonging to this extension. storage is the only permission it asks for, used to remember where you left the panel. Two kinds of request leave your browser — the public set-data files and Pokémon sprites — and both are described in the privacy policy.

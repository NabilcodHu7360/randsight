1a. Code carried inside @smogon/calc, whose notices the minifier strips
-----------------------------------------------------------------------

@smogon/calc's src/util.ts carries two attribution comments for code adapted
from other projects. Both are compiled into src/vendor/calc.js, and esbuild's
minifier removes the comments, so they are restated here:

    // https://github.com/krzkaczor/ts-essentials v6.0.5
    // MIT License Copyright 2018-2019 Chris Kaczor

    // jQuery JavaScript Library v2.0.3
    // Copyright 2005, 2013 jQuery Foundation, Inc. and other contributors

The ts-essentials attribution covers TypeScript type declarations only, which
have no runtime representation in the bundle. The jQuery-derived type-detection
table is present in the shipped bundle. jQuery 2.0.3 was released under the MIT
licence.

2. Pokémon Showdown  —  source of the joint tables in src/data/
--------------------------------------------------------------------------

The fourteen files src/data/joint-*.json are shipped in the extension package.
They are not hand-written: scripts/build-joint.js requires the
`pokemon-showdown` package and calls its own team generator (`Teams.generate()`)
tens of thousands of times per format, recording the sets it produces. The
shipped tables are therefore derived directly from Pokémon Showdown's Random
Battle set generator and its dex data.

3. pkmn/randbats  —  fetched at runtime, not shipped
--------------------------------------------------------------------------

The published Random Battle statistics at data.pkmn.cc/randbats/stats/ come
from https://github.com/pkmn/randbats, which is MIT licensed. That data is
downloaded by the user's own browser at runtime and cached locally; no copy of
it is redistributed in this package, so no notice is required here. It is
credited in README.md and in the extension's own guide.
